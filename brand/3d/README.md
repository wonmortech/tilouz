# 3D

`tilo-symbol.glb` is the symbol extruded, generated by `brand/src/glb.py` from the same arcs as the SVG (pure Python, checked with the Khronos glTF validator: 0 errors, 0 warnings). `tilo-symbol-render.png` is a three.js preview.

## Model

- glTF 2.0 binary, Y up, 1 unit = 100 artboard units (the wave is 3.72 units wide), origin at the joint of the two halves.
- Three nodes under `tilo-symbol`: `arc-left`, `arc-right`, `dot`, each with its own material (`tilo-arc-left` teal, `tilo-arc-right` sea, `tilo-dot` gold metal). Animate them like the 2D motion states.
- Depth 0.35w (21 u = 0.21 units). The halves are 0.5 u apart at the joint so their faces never z-fight.
- Flat caps, smooth side normals on curves, hard edges at the flat joint.

## Look

| Part | Material |
|---|---|
| Halves | Matte silk plastic: roughness 0.45, metalness 0, base colour teal `#0B7A67` / sea `#1497B8` |
| Dot | Gold metal: metalness 1, roughness 0.25, `#F2A81D` |

Light: a large softbox top-left plus a rim light behind. Background: paper `#F7F5F0` or teal 950 `#09211B`. Bevel (add in Blender, the GLB has none): 0.08w (5 u), 3 segments, outer edges only, the joint faces stay flat.

## three.js

```js
import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

new GLTFLoader().load('/brand/assets/3d/tilo-symbol.glb', (gltf) => {
  const mark = gltf.scene;                       // children: arc-left, arc-right, dot
  scene.add(mark);
  const right = mark.getObjectByName('arc-right');
  // "connecting": slide the right half 2R (1.56 units) left to close the ring
  right.position.x = -1.56 * easeInOut(t);
});
```

Respect `prefers-reduced-motion`: render one still frame instead of a loop.
