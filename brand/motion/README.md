# Motion

The symbol moves the way a conversation moves: two halves that come together. Motion is pure SVG + CSS (no Lottie, no runtime library), so it works in the web app, in `<img>` tags and in native web views.

## Tokens

| Easing | Value | Use |
|---|---|---|
| expo | `cubic-bezier(.16,1,.3,1)` | Entrances, the intro |
| spring | `cubic-bezier(.34,1.56,.64,1)` | The dot landing (small overshoot) |
| in-out | `cubic-bezier(.65,0,.35,1)` | Morphs: wave to ring and back |
| sine | `cubic-bezier(.37,0,.63,1)` | Loops: idle, listening |
| linear | `linear` | Continuous spin only |

Durations: instant 120 ms, fast 200 ms, base 320 ms, slow 560 ms, intro 1100 ms.

## States

All distances are in artboard units (the symbol is drawn on a 512 artboard; the wave is 372 u wide).

| State | Duration | Easing | What happens | When |
|---|---|---|---|---|
| **intro** (assemble) | 1100 ms once | expo + spring | Halves turn 180 degrees about their own centres and slide 70 u in from both sides (760 ms); the dot drops from 90 u above and lands at 560 ms (520 ms, spring). The wordmark writes itself: t-i in one stroke (640 ms), t-bar, l, the o closes from two halves, the i-dot lands last. | App launch, website hero, video idents. Once per session. |
| **idle** | 4.8 s loop | sine | Halves breathe 5 u apart, the dot floats 6 u. | Splash, empty states. Never behind text. |
| **listening** | 900 ms loop | sine | Halves scale vertically 0.78-1.08 like an audio level, right half 150 ms behind; the dot pulses 1.3x. | The app is listening to speech. Drive amplitude from the real input level if available. |
| **captioning** | 1 s loop | steps + sine | The dot blinks like a text cursor (steps), halves type 3 u side to side. | Live captions are being written. |
| **connecting** | 1.8 s loop | in-out | The right half slides 2R (156 u) left and joins the left half into an "o" ring, the ring turns 360 degrees, then it returns to the wave. The dot rests in the counter at 0.55x. | Calling an interpreter, joining a call. |
| **loading** | 1.2 s loop | linear | The joined ring spins; the dot breathes in the counter. | Buttons, small spinners, data loading. |
| **transition** | 700 ms once | in-out | Halves part 24 u and fade, the dot lifts 40 u, then all return. | Screen changes, a call ending. |

## Reduced motion

`prefers-reduced-motion: reduce` stops every animation and shows the final, static logo. Loading keeps a slow opacity blink of the dot (state must still be visible); connecting shows the static wave plus a text label ("Ulanmoqda..."). Never rely on motion alone to communicate state: always pair it with a word or a status icon.

## Files

- `svg/tilo-motion-<state>.svg`: one self-contained animated SVG per state (works as `<img src>`).
- `svg/tilo-lockup-intro-color-light.svg`, `-color-dark.svg`: the full horizontal logo assembling.
- `reference/tilo-motion.css`: every keyframe and state selector (generated by `brand/src/build.py`).
- `reference/tilo-motion.js`: a 30-line controller, no dependencies: `TiloMotion.set(svg, 'listening')`, `TiloMotion.replay(svg)`, and `data-then="idle"` to hand over after intro.
- `reference/index.html`: a demo page (open it through any static server).

Markup contract: an inline `<svg class="tilo-motion" data-state="intro" viewBox="0 0 512 512">` containing `<g class="t-all">` with `.t-l` (left half), `.t-r` (right half), `.t-d` (dot). For the wordmark: `.w-ti`, `.w-t-bar`, `.w-l`, `.w-o-top`, `.w-o-bottom` with `pathLength="1"`, and `.w-i-dot`.
